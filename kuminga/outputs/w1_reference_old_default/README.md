# Reference snapshot: the OLD DEFAULT minutes blend (50/50 for everyone)

Frozen 2026-09-09, immediately before the W1 team-changer rule was applied, so the
before/after comparison is reproducible rather than remembered.

Under this snapshot every player, mover or incumbent, had desired minutes set as a
50/50 blend of the empirical rank curve and his own prior minutes per appearance.
Cody Williams was allocated 19.24 minutes on a prior of 24.34 carried over from a
27-win Utah team.

The W1 rule reweights team-changers to 80/20 toward the curve and leaves incumbents
at 50/50. `w1_compare.py` reads this directory as the "old default" column.
