# Pricing the LaMelo Trade, visualization set

Ten fragments for the three-part series, built to the viz-builder contract
(D3 v7 global, design tokens, scroll passthrough, watermark Jul 2026).
Every number is embedded from the FINAL exports (freeze 50f9b7bc5b19835b,
Engine D seed 20330706, swap_pricing_FINAL); nothing is invented.
The `preview_part*.html` files are GENERATED by the build script, do not
edit them by hand; the `*_fragment.html` files are canonical.

Publish per fragment at /admin/visualizations/new with the vizId and
altText below, then the article shortcode (already placed in the drafts).

## Part 1, The Tenure Bet (stage1 draft v3)

|---|---|---|---|
