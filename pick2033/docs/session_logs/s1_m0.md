   37 balls (3/2/1 by play-in role; worst-3 relegated to 2), ALL 16 picks
   drawn, PLUS: top-12 floor for the worst three, no consecutive #1, no top-5
   in three straight drafts. The cross-year constraints make lottery years
   dependent 2027-2033: Engine D must carry lottery history per path. Play-in
   simulation is now REQUIRED in Engine D (ball counts depend on play-in
   roles). Sources: NBA.com BoG release, CBS, ESPN, Wikipedia. Drawing
   micro-mechanics are not public -> assumptions A1-A6 documented in lottery.py.

   R-hat 1.00 that way). Latent form only if backtests earn it, with
   sigma_obs pinned.

## Post-review bugfix (2026-07-01, same day)
Bobby's annotated review caught an arrival-year bug: the departure test
included a same-season stint count (n_franchises > 1), which carries no
direction, so mid-season ARRIVAL years auto-closed spells as departures
(10 adjacent same-franchise pairs + 4 falsely-closed arrival spells).
Fix: departure derives ONLY from cross-season final-stint comparison; spells
persist without re-qualification; boundary exits censored by definition.
Also: tenure clock no longer resets on same-franchise gap years (MJ CHI 1998
tenure = 14). Result: 319 spells (10 pairs merged), zero adjacent pairs,
all 39 boundary exits censored. 8 regression tests added
(tests/test_star_spells.py); suite now 35 green. Annotations carried onto the
regenerated CSV via src/etl/merge_review_annotations.py (130 carried, 24
AGENT_FIX resolved, 0 unmapped). Bobby's judgment overrides (KEEP/PRUNE/
BORDERLINE, SET exit_type, July-6 updates) apply at the M2 re-import.
